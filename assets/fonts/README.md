# Bundled Fonts

Kerosene embeds these font files so users can choose them from Settings.

- `Inter-Variable.ttf` is Inter, also used by papertrade.xyz's landing page and
  exchange (`--font-ui: Inter,system-ui,-apple-system,sans-serif`). It is already
  bundled and independently selectable under Display Font and Monospace Font;
  selecting the Papertrade theme does not change either font preference.
  - https://github.com/rsms/inter
  - https://github.com/google/fonts/tree/main/ofl/inter
- Inter is licensed under the SIL Open Font License 1.1; see `Inter-OFL.txt`.
- `UbuntuSans-Variable.ttf` and `UbuntuSansMono-Variable.ttf` are from Canonical's Ubuntu Sans repositories:
  - https://github.com/canonical/Ubuntu-Sans-fonts
  - https://github.com/canonical/Ubuntu-Sans-Mono-fonts
- The Ubuntu font files are licensed under the Ubuntu Font Licence 1.0; see `Ubuntu-Font-Licence-1.0.txt`.
- `Quantico-Regular.ttf`, `Quantico-Bold.ttf`, `Quantico-Italic.ttf`, and
  `Quantico-BoldItalic.ttf` are from Google Fonts:
  - https://fonts.google.com/specimen/Quantico
  - https://github.com/google/fonts/tree/main/ofl/quantico
- The Quantico font files are licensed under the SIL Open Font License 1.1; see
  `Quantico-OFL.txt`.
